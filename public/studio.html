L’empreinte est un WAV de référence associé durablement à cet avatar. Changer le texte d’une génération ne changera plus son identité vocale.

Empreinte active

Pour afficher un texte ou une formule en bas de la vidéo : {Texte: Bonjour} ou {Latex: x+1}, suivi des paroles. {} termine l’affichage. Ces commandes ne sont pas prononcées.

Pour remplacer l’avatar par une image pendant les paroles : {Image: une licorne}. {} fait revenir l’avatar. Une description identique réutilise la même image.

Pour afficher une ressource enregistrée, tapez {Ref: : choisissez son type puis son nom dans la fenêtre proposée. La commande {Ref:FormuleEnergie} est complétée automatiquement. Ajoutez ensuite les paroles ; {} fait revenir l’avatar.

Pour insérer une image ou une vidéo du serveur : {File:/chemin/fichier.mp4}. Si la vidéo possède du son, les paroles reprennent avec l’avatar après sa lecture.

Chaque commande visuelle doit être suivie de paroles. Pour écrire des accolades dans les paroles : \{exemple\}.

La voix utilisera automatiquement l’empreinte de cet avatar.
